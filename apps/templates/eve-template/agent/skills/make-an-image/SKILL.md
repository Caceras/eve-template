# Making an image

`generate_image` produces the picture. Each call costs money and takes time, so the work is in the prompt, not in the retries. If generation is unavailable, say so plainly; never claim an image exists without a successful tool result.

## Expand the request, do not just forward it

"A cat" is a request, not a prompt. Settle the four things the image model cannot guess:

1. **Subject**: what is in it, specifically. Not "a person" but "an older woman in a green raincoat, mid-stride".
2. **Composition**: where the camera is. Close-up, wide, from above, what is in the foreground.
3. **Light**: the biggest lever on whether an image looks made or found. Overcast, low winter sun, a single lamp, backlit.
4. **Medium and finish**: photograph, oil, flat vector, pencil. Name it even when it seems obvious.

Write it as description, not a list of keywords.

## Say what must not be there

"No text", "no people" and "no logos" are worth stating when the use implies them. An image that will sit behind a headline needs a quiet area for it.

## Match the format to the use

Pick the aspect ratio from the purpose (cover, avatar, slide background, inline illustration). Ask only when the purpose is unclear and the shape matters.

## Show the prompt you used

Put the expanded prompt in the reply so the user can correct one word instead of re-describing everything.

## Do not iterate silently

If the result is wrong, say what you would change and why, then change one thing.
